# WCET-analyzer

Программа для анализа наихудшего (WCET) и наилучшего (BCET) времени выполнения программного фрагмента в системах реального времени.

## Описание варианта
- **Тема:** Кодирование сообщения помехоустойчивым кодом (код Хэмминга).
- **Исследуемые задержки:** Промахи кэш-памяти и ошибки предсказателя ветвлений.

## Структура проекта
- `data/` - конфигурационные JSON-файлы с параметрами процессора и операциями;
- `src/` - исходный код анализатора (`wcet_analyzer.py`);
- `docs/` - документация и итоговый отчёт.

## Технологии

| Технология | Назначение |
| --- | --- |
| **Python 3.10+** | Основной язык разработки |
| `dataclasses` | Описание структур данных для задач, операций и параметров процессора |
| `json` | Чтение конфигурационных файлов вариантов (`variant_coding.json`) |
| `pathlib` | Управление путями к файлам проекта в кроссплатформенном формате |
| `typing` (`List`, `Dict`, `Tuple`, `Optional`) | Статическая типизация для повышения надежности кода |
| **Git / GitHub** | Система контроля версий и управление ветками (`docs/report`) |
