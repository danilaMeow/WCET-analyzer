# WCET-analyzer

Программа для анализа наихудшего (WCET) и наилучшего (BCET) времени выполнения программного фрагмента в системах реального времени.

## Описание варианта
- **Тема:** Кодирование сообщения помехоустойчивым кодом (код Хэмминга).
- **Исследуемые задержки:** Промахи кэш-памяти и ошибки предсказателя ветвлений.

## Структура проекта
- `data/` - конфигурационные JSON-файлы с параметрами процессора и операциями;
- `src/` - исходный код анализатора (`wcet_analyzer.py`);
- `docs/` - документация и итоговый отчёт.

## Запуск
```bash
python src/wcet_analyzer.py data/variant_coding.json
